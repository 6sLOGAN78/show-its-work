# `data/` - Datasets & State

This directory stores the synthetic data generated by the application, as well as offline storage state.

## Structure
- `synthetic/`: Contains `.parquet` and `.csv` files representing simulated business data (orders, telemetry logs, reviews, etc.). The engine queries these files to calculate metrics and validate hypotheses.
- `state/`: Stores the `.jsonl` files for application memory and telemetry (such as `episodic_memory.jsonl` and `telemetry.jsonl`).
